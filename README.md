# TCOSC Website

## Tanzania Computing Open Source Community

This repository contains the official public website of the
Tanzania Computing Open Source Community (TCOSC).

TCOSC is an open computing community focused on learning,
practical development, open-source collaboration, research,
knowledge sharing, contribution, and mentorship across
Tanzania's computing community.

## Website

https://tanzania-computing-open-community.github.io/

## TCOSC GitHub Organization

https://github.com/tanzania-computing-open-community

## Core Communities

- Tanzania Computing Students
- Tanzania Cybersecurity
- Tanzania Software Development

## Community Model

LEARN → PRACTICE → BUILD → SHARE → COLLABORATE →
CONTRIBUTE → REVIEW → MAINTAIN → MENTOR

## Purpose of This Repository

The website serves as the public-facing layer of TCOSC.

It provides a central place to discover:

- TCOSC
- Computing communities
- Learning resources
- Projects
- Research
- Community activities
- Events
- Mentorship
- Contribution opportunities
- Institutional participation

GitHub remains the primary collaborative working environment
for TCOSC projects and community contributions.

## Development

The website is developed incrementally with an emphasis on:

- Accessibility
- Performance
- Responsive design
- Security
- Maintainability
- Clear technical structure
- High-quality content
- Open-source principles

## Technology

The initial website will use:

- HTML5
- CSS3
- JavaScript

Additional technologies may be introduced later when there
is a genuine technical requirement.

## Content Policy

Website content must represent real TCOSC activities,
projects, research, contributors, events, institutions and
achievements.

The website must not contain fabricated:

- Statistics
- Projects
- Partnerships
- Contributors
- Events
- Testimonials
- Institutional relationships
- Achievements

## Contribution

Website contributions should follow the TCOSC contribution
guidelines and normal GitHub workflow.

Contributors should review the relevant community
documentation before submitting changes.
