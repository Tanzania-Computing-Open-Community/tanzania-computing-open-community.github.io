ABOUT TCOSC

An open community for Tanzania's computing ecosystem.

Tanzania Computing Open Source Community (TCOSC) is a national open computing community built around knowledge, practical skills, open-source contribution, research, collaboration, and mentorship.

TCOSC provides a shared environment where people can learn technical skills, put those skills into practice, build real projects, exchange knowledge, contribute to open source, conduct research, and help others grow.

Why TCOSC?

Computing knowledge and practical experience should not remain isolated within individual classrooms, institutions, projects, or communities. TCOSC creates a space where knowledge and technical work can move between people, institutions, projects, and the wider open-source ecosystem.

LEARN

Learn skills. Practice them. Use them.

TCOSC organizes technical learning around practical computing skills rather than limiting knowledge to course titles.

Programming

Languages, algorithms, data structures, programming practice, and problem solving.

Software Development

Application development, architecture, testing, version control, and maintenance.

Web Technologies

Web development, HTTP, APIs, browsers, backend systems, and modern web platforms.

Networking

Network fundamentals, protocols, infrastructure, services, and practical network engineering.

Systems

Operating systems, Linux, Windows, system administration, and computing infrastructure.

Cybersecurity

Security fundamentals, defensive practices, laboratories, research, and responsible security testing.

Research

Research methods, technical investigation, experimentation, documentation, and reproducible work.

Open Source

Git, GitHub, contribution workflows, project collaboration, licensing, and maintenance.
